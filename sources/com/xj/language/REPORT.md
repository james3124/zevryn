# Area report — language / string resources (Rust port)

Reference (read-only): `sources/com/xj/base/language/GHLocaleManager.java` and
`resources/res/values[-*]/strings.xml` of GameHub Lite v5.1.8. All Rust code is
dependency-free (std only), with `#[cfg(test)]` unit tests. Layout follows
`PLAN.md`: a `mod.rs` plus sibling `.rs` files at the mirrored Java package
path, to be wired from `app/src/lib.rs` with a `#[path]` declaration.

## Files created

| File | Purpose |
|---|---|
| `sources/com/xj/language/mod.rs` | Package root: `pub mod` declarations and re-exports (`StringsCatalog`, `Locale`, `PrimaryLocale`, `SupportedLocales`, `parse_strings_xml`, `decode_xml_text`, …). |
| `sources/com/xj/language/strings_xml.rs` | Minimal Android `strings.xml` reader. `parse(&str) -> Result<HashMap<String,String>, ParseError>` handles `<string name="…">value</string>`, self-closing tags, quoted/`formatted="false"` attributes, XML entities (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`, `&nbsp;`, `&#NN;`, `&#xHH;`), Android escapes (`\'`, `\"`, `\\`, `\n`, `\t`, `\r`, `\@`, `\?`, `\uXXXX`), comments and non-`string` elements. Single-pass decode avoids double-unescaping. |
| `sources/com/xj/language/locale.rs` | `Locale` (`language`/`region`/`script`) with `parse_tag` (`zh-rCN`, `en-rUS`, `b+es+419`, `b+sr+Latn`), `to_language_tag`, and `GHLocaleManager`-compatible storage format (`n`/`l`/`r`/`q`: `"zh$CN"`). `SupportedLocales` + `BASE_LOCALES`/`REGIONAL_LOCALES` mirror the shipped `values-*` directories; `resolve("zh-rCN") == Some("zh")`. `PrimaryLocale` mirrors the zh/ja/ru/default branches in `GHLocaleManager.f()`/`.h()`. |
| `sources/com/xj/language/strings_catalog.rs` | `StringsCatalog`: base catalog + per-locale maps. `lookup(key, locale)` tries the exact tag, then the base language (plus legacy aliases `in/id`, `iw/he`), then the base catalog. |
| `sources/com/xj/language/REPORT.md` | This report. |
| `resources/res/values/strings.xml` | Local copy of the base `values/strings.xml` (3,533 `<string>` declarations), so resource lookup/tests work without the reference tree present. |

The language module re-exports `pub` items; when `lib.rs` wires it as
`pub mod language` there are no dead-code warnings.

## Locale coverage

`BASE_LOCALES` (69) and `REGIONAL_LOCALES` (26) were derived from the actual
`values-*` directory names in the reference. Density/version qualifiers
(`hdpi`, `night`, `v27`, `watch`, …) are correctly excluded. Key locales
`en, zh, ja, ru, de, fr, es, ko, pt` and regional variants (`zh-rCN`,
`en-rUS`, `pt-rBR`, `b+es+419`, …) are all present.

## String provenance: first-party vs library-generated

The base file contains **3,533** names. Roughly **295** are generated by bundled
libraries; about **3,238** are first-party (GameSir / GameHub).

**Library-generated prefixes** (classified in the parser as ordinary strings —
the catalog does not special-case them, but they are not product copy):

| Prefix | Origin | Count |
|---|---|---|
| `abc_` | AndroidX AppCompat | 27 |
| `mtrl_`, `material_`, `m3_`, `bottomsheet_`, `appbar_`, `bottom_sheet_` | Material Components / Material 3 | 110 |
| `cast_` | Google Cast | 52 |
| `exo_` | ExoPlayer | 52 |
| `common_google_play_services_*`, `common_signin_*`, `common_open_on_phone` | Google Play services | 18 |
| `character_counter_*`, `clear_text_end_icon_*`, `password_toggle_*` | Material text field | 5 |
| `emoji_` | emoji library | 12 |
| `ando_str_*` | AndPermission (untranslated Chinese leftovers) | 5 |
| `business_xgp_*` | XGP SDK | 5 |
| `ijkplayer_`, `authsdk_`, `androidx_startup`, `default_*`, `status_bar_*`, `common_share_translation_*`, `define_*` | misc libraries / build placeholders | 14 |

**First-party prefixes** (product copy): `llauncher_`/`llanucher_` (landscape
launcher), `winemu_`, `pc_`, `tp_`, `mapping_`, `psstream_`/`ps_`, `comm_`,
`title_`, `xja_`, `ota_`, `preferences_`, `cloud_`, `steam_`, `keybtn_`,
`config_`, `devicesetting_`, `alert_`, `action_`, `adb_`, `bussiness_`,
`game_`, `applist_`, `dialog_`, `regist_`, `rts_`, `library_`, plus standalone
keys such as `app_name`, `follow_system`, `cancel`, `confirm`.

Note: some first-party strings still contain untranslated Chinese literals in
the base file (e.g. `ando_str_*`, `comm_game_data_error`, `comm_launching`);
the parser preserves them verbatim rather than "fixing" them.

## Verification

Compiled and tested standalone with a temporary Cargo harness that wires
`mod.rs` via `#[path]`; **14 tests pass, 0 failures, 0 warnings**. Tests cover:
inline XML fixture (escapes/entities/self-closing/comments), entity edge cases,
missing-name errors, reading the real reference `strings.xml` at its absolute
path (with a local-copy fallback and a graceful skip when absent), locale tag
parsing/resolution, the supported set, storage round-trips, primary-locale
branches, catalog base/region/alias fallback, and a real-file catalog load.
